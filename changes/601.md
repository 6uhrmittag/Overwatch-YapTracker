### A busy PC no longer makes the capture restart itself (#601)
- In a match the game can take every core and YapTracker waits. That wait was taken for the game's picture stopping, so the capture restarted itself and lost chat meanwhile. Now it's told apart: only a picture that really stopped restarts it.
- While YapTracker waits for a core it reads the chat every 3 s for a minute, whatever is chosen in Settings (also "as fast as it can"). Lines stay about 9 s on screen, so none is missed by that.
